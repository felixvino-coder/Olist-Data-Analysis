# 🛒 Olist E-Commerce Analytics Dashboard & Data Pipeline

## 📌 Project Overview
An end-to-end business intelligence project analyzing Olist's e-commerce operations in Brazil. 
This project bridges custom SQL data architecture in MySQL with an interactive Tableau dashboard to deliver actionable business insights.

## 🗄️ SQL Architecture & Key Insights
1. **Fulfillment Funnel (`view_cancellation_funnel`)**: Tracks order cancellations across fulfillment stages.
2. **MoM Revenue (`view_mom_revenue`)**: Analyzes monthly GMV trends and growth rates.
3. **Category Dominance (`view_category_highest_revenue_month`)**: Highlights top-performing product categories per month.
4. **Logistics & Reviews (`view_delivery_impact_on_reviews`)**: Measures the impact of late delivery on customer review scores.
5. **Regional Strategy (`view_regional_top_category`)**: Maps state-level revenue distribution.
