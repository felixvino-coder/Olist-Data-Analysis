## 📁 SQL Data Architecture
- `view_cancellation_funnel`: Analyzes order cancellations across lifecycle stages.
- `view_mom_revenue`: Tracks Month-over-Month GMV growth trend.
- `view_category_highest_revenue_month`: Identifies monthly dominant product categories.
- `view_delivery_impact_on_reviews`: Evaluates the impact of late delivery on customer rating.
- `view_regional_top_category`: Maps best-selling categories per Brazilian state.
